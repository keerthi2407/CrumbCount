# CrumbCount 🧁
### Every crumb counts. Every decision matters.

**A Home Bakery Intelligence & Data Analytics Project**

CrumbCount is a data-driven project focused on understanding and improving the operational and financial decisions of small home bakeries.

The project explores how data analytics can help home bakers manage production costs, ingredient inventory, pricing, sales performance, profitability and unsold products.

Rather than simply presenting business data through dashboards, CrumbCount aims to transform raw operational data into meaningful insights that support better decision-making.

## 🎯 Project Objectives

- Analyse recipe and production costs.
- Evaluate product pricing and profitability.
- Monitor ingredient inventory and wastage.
- Understand sales trends and customer preferences.
- Analyse unsold products and batch performance.
- Explore demand forecasting and production planning.
